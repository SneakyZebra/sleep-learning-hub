# Sleep Learning Hub

An independent sleep medicine and sleep technologist resource directory, using the navy and green visual style of the EEG Learning Hub.

## Sections
- CEU Directory: free, paid or membership, and verify cost and credit
- General Education
- Videos
- Conferences
- Registry Prep: RPSGT, CPSGT and CCSH
- Toolkit: renewal progress, favorites, completed education tracker and CSV export

## Editorial policy
Prioritize BRPT, AASM and AAST primary sources. Verify individual activity cost, current credit approval, eligibility, deadlines and completion rules. Membership benefits are not universally free. Do not treat archived activities or pending credit approval as current verified free CEUs. The initial review did not confirm a current universally free credit activity; promising sources are accurately marked for verification.

resources.json records source URLs, access classifications and review dates. index.html embeds the same data for a self contained site. Keep both synchronized after editing. User tracker and favorite records stay in browser localStorage under a sleep specific namespace. No patient information or certificates are uploaded.

## Hosting
index.html can be published from the main branch root using GitHub Pages when the repository and account plan are eligible. Source is initially private. On the current account GitHub requires a plan upgrade or a public repository before Pages can be enabled.

This directory is not affiliated with or endorsed by BRPT, AASM or AAST. Course availability and credential requirements can change.
